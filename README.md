## Descrição

O ShowMate é um aplicativo mobile, inspirado no antigo TV Time, para acompanhar filmes e séries. A ideia é organizar em um único lugar o que o usuário já assistiu, o que está assistindo e o que pretende assistir.

Desenvolvido com React Native e Expo, com a identidade visual Dark Blue.

## Telas disponíveis

- **Home:** boas-vindas e lista de títulos em destaque.
- **Descobrir:** campo de busca para filtrar filmes e séries pelo nome.
- **Biblioteca:** formulário para adicionar títulos (com validação) e lista dos itens adicionados.
- **Perfil:** área reservada para as estatísticas do usuário.

## Tecnologias

- React Native
- Expo
- JavaScript
- React Navigation (navegação por abas)

## Como executar

1. Instale o [Node.js](https://nodejs.org).
2. Clone o repositório:

```
git clone https://github.com/caiohbiaco/ShowMate.git
```

3. Entre na pasta do projeto:

```
cd ShowMate
```

4. Instale as dependências:

```
npm install
```

5. Inicie o aplicativo:

```
npx expo start
```

6. Instale o app **Expo Go** no celular ou tablet e escaneie o QR Code exibido no terminal.

## Créditos e atribuições

O ShowMate utiliza a API do [The Movie Database (TMDB)](https://www.themoviedb.org/) para consultar informações sobre filmes e séries, incluindo títulos, sinopses, pôsteres, avaliações e elenco.

This product uses the TMDB API but is not endorsed or certified by TMDB.
